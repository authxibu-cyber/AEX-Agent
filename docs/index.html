Flagship Capabilities

Everything a long-horizon agent needs

Built for persistent, autonomous work — not throwaway chat sessions.

🖥

Full-Screen Terminal TUI

Textual app with docked header, scrollable transcript, tool-call cards, and a live telemetry bar: context gauge, stream health, latency, token flow.

🧠

3-Layer Bounded Memory

MEMORY.md for world facts, USER.md for user traits — FIFO-bounded so context stays lean, plus SQLite FTS5 search across every past session.

⚡

Self-Written Skills

The agent authors its own SKILL.md packages (/learn, agentskills.io standard) and loads them into future sessions automatically.

🔌

Any Provider, Any Endpoint

13 built-in providers plus custom for any OpenAI-compatible API. Masked key entry, live connection test before saving. Switch mid-session with aex model.

📡

Multi-Channel Gateway

FastAPI server on :8642 exposing OpenAI-compatible /v1/chat/completions (SSE) — connect Open WebUI, LangChain, or the Telegram / Discord / Slack bridges.

⏱

Cron & Subagents

Natural-language scheduled automations with conversational memory injection, plus parallel subagent delegation to collapse long tasks into single turns.

The Closed Loop

How AEX Agent improves itself

1

Act

Agent executes your task with terminal, file, web, and code-sandbox tools.

2

Distill

High-salience outcomes are written into bounded persistent memory automatically.

3

Synthesize

Reusable procedures become executable SKILL.md packages via /learn.

4

Recall

Next sessions load skills, memory, and FTS5 history — the agent starts smarter.
