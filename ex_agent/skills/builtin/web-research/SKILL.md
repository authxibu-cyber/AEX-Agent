# Deep Technical Reconnaissance Protocol

When invoked to perform web research:
1. **Multi-Angle Querying:** Issue diverse, specific search queries targeting primary sources, official documentation, GitHub repos, and preprints.
2. **Signal Extraction:** Discard marketing prose. Extract exact APIs, configuration schemas, benchmark numbers, and architectural trade-offs.
3. **Structured Synthesis:** Produce a concise executive technical briefing with citations, code snippets, and failure mode analysis.
